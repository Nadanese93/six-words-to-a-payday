A six-word story entry for the **Six Words to a Payday** bounty on
[make.fun](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f?utm_source=github&utm_medium=readme&utm_campaign=u-irvan-motion-six-words-to-a-payday-89fb591f),
a coding bounty competition paying USDC on Solana. This contest offers a
2 USDC prize pool to the top 10 entries, judged head-to-head.

## Entry

The program writes a single six-word story to `entry.txt` — a complete
story with a twist and a warm beat, told in exactly six words.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/path/to/out python3 main.py
```

The program writes `entry.txt` into the output directory and verifies
the written bytes on disk before exiting. No network access, no
randomness — the output is deterministic.
